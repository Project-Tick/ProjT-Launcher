# Security Policy

## Supported Versions

ProjT Launcher actively maintains the following release branches.  
Only the versions listed as *Supported* will receive security patches.

| Version             | Supported |
| ------------------- | --------- |
| 10.x (current)      | ✔         |
| 9.x                 | ✔         |
| 8.x                 | ✖         |
| < 8.x               | ✖         |

Security fixes are applied only to supported branches. Older versions must be upgraded.

---

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly.

### How to report

If you found a security issue, please contact us via:

- Email: [`froster12@naver.com`](mailto:froster12@naver.com)

### What to include

Please provide:

- A clear description of the issue  
- Steps to reproduce  
- Potential impact (RCE, crash, information leak, etc.)  
- A proof-of-concept if available  
- Affected platform (Linux, macOS, Windows)

### Response expectations

- You will receive an acknowledgment within **48 hours**  
- A preliminary assessment within **5 working days**  
- If the vulnerability is confirmed, you will be informed about:
  - Severity classification (Low / Moderate / High / Critical)
  - Timeline for patch release
  - Whether you qualify for credit in the changelog

### Disclosure Policy

ProjT follows responsible coordinated disclosure:

1. The issue will be privately investigated.  
2. A fix will be developed and shipped.  
3. Security advisories will be published after the patch release.  
4. Credit will be given unless anonymity is requested.

Do not open public GitHub issues for security vulnerabilities.
